# 云路邮差

手机竖屏优先的浏览器游戏：一指画出云路，护送邮车完成配送，再用收益重建浮空小镇。

## 在线试玩

<https://kevinkaslana093.github.io/cloudway-postman/>

## 已实现内容

- 5 个逐步变难的配送关卡、移动障碍、收集物、灯塔护盾与中继三选一。
- 小镇建筑、公司部门、角色能力、等级、金币与邮票持久化成长。
- 本地援助券模拟激励视频成功回调；当前没有真实广告、付费或账号系统。
- 触屏/鼠标画路、程序化音效、自动存档、30/60 帧与画质、左右手及减少动态设置。

## 本地运行

```bash
npm install
npm run dev
```

## 操作

- 触屏/鼠标：在邮车前方按住并画出道路。
- 灯塔：开启短暂护盾，抵挡一次障碍碰撞。
- Esc：暂停。

游戏进度保存在浏览器本地，无账号、无付费、无真实广告。`main` 分支通过 GitHub Actions 自动部署到 GitHub Pages。
